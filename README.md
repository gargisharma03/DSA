# DSA

This repository contains the DSA problems I solve while learning and practicing Data Structures and Algorithms.

I add problems to the repository whenever I have time to document my learning. For the problems I do add, I usually include:

* **Statement** — Problem description
* **Approach** — The intuition and steps I used to solve the problem
* **Complexity** — Time and space complexity
* **Code** — C++ implementation

The purpose of this repository is to keep track of the problems I have worked on, understand different problem-solving approaches, and improve my DSA skills over time.

This is an ongoing collection, so it may not contain every problem I solve.
